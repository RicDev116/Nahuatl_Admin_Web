# Reglas de Control de Versiones

Para evitar duplicidad de información, tu comportamiento respecto a Git está delegado al documento principal del proyecto.

**REGLA OBLIGATORIA:**
Antes de realizar cualquier operación de control de versiones (como crear ramas, hacer commits, o hacer push), **DEBES leer obligatoriamente el archivo `GIT_GUIDELINES.md`** ubicado en la raíz de este proyecto y acatar todas sus directrices estrictamente.

Nunca tomes decisiones de GitFlow o Conventional Commits sin basarte en lo que dicte ese documento.
